# Pawdays

Pawdays is a lightweight SwiftUI iOS app concept inspired by the calm, card-based journaling feel of Cafeor · Coffee Tracker, but focused entirely on pet care records.

## Concept

- Browse pets with profile cards.
- Track daily records like meals, walks, mood, health, and grooming.
- Review a recent timeline and compact daily stats.
- Keep the interface soft, minimal, and diary-like.

## Structure

- `Pawdays/Models`: app data models.
- `Pawdays/ViewModels`: sample state and derived stats.
- `Pawdays/Views`: reusable SwiftUI sections/cards.
- `Pawdays/ContentView.swift`: app home screen composition.

## Notes

This repository currently contains a starter prototype UI with local sample data and no persistence yet.
